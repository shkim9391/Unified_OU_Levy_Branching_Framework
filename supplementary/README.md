# Supplementary Materials

This directory contains the supplementary information, curated supplementary
data files, source outputs, and figure-generation scripts accompanying:

**A Unified Ornstein–Uhlenbeck–Lévy–Branching Framework for
Interpretable Modeling of Cancer Evolution**

## Supplementary Information

`Supplementary_Information.pdf`

Includes:

- Supplementary Notes 1–10
- Supplementary Figures S1–S6
- Supplementary Tables S1–S8

## Curated Supplementary Data

### Supplementary Data 1

`data/Supplementary_Data_1_Simulation_Parameters.xlsx`

Parameter configurations, replicate definitions, random seeds, and exact
simulation and inference settings used for Supplementary Figures S1–S6.

### Supplementary Data 2

`data/Supplementary_Data_2_OU_Parameter_Recovery.csv`

Replicate-level recovery results for the OU attractor, mean-reversion, and
diffusion parameters.

### Supplementary Data 3

`data/Supplementary_Data_3_Levy_Jump_Detection.csv`

Trajectory-level Lévy jump-detection results, including jump-time and
jump-size recovery and classification outcomes.

### Supplementary Data 4

`data/Supplementary_Data_4_Branch_Reconstruction.xlsx`

True and inferred branch assignments, aligned probabilities, transition
matrices, and separation-sensitivity results.

### Supplementary Data 5

`data/Supplementary_Data_5_Full_OULB_Recovery.xlsx`

Integrated OULB recovery results, including jump localization, branch
reconstruction, parameter recovery, and held-out prediction.

### Supplementary Data 6

`data/Supplementary_Data_6_Sensitivity_Analyses.csv`

Replicate-level sensitivity results across observation noise, sampling
irregularity, missingness, sample size, and latent-state dimension.

## Source Outputs

The `source_outputs/` directory contains the direct CSV outputs generated by
the Supplementary Figure S2–S6 scripts. These files are retained to provide
a transparent link between the executable scripts, curated Supplementary
Data files, and published figures and tables.

## Reproducibility

Scripts for regenerating Supplementary Figures S1–S6 are located in:

`scripts/supplementary_figures/`

Simulation parameters and random-seed mappings are documented in
Supplementary Data 1.
